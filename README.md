# Espaço Vende Mais

Site de anúncios do Espaço Vende Mais. O primeiro produto é um Volkswagen Gol CL 1.6 MI 1997.

## Publicação

Esta pasta contém os arquivos estáticos publicados pelo GitHub Pages em <https://otalchriis.github.io/espaco-vende-mais/>. O arquivo `index.html` é a página inicial. A pasta `assets` contém as fotos e os vídeos editados para o anúncio.

## Atualizações

As alterações na branch `main` podem ser publicadas pelo GitHub Pages a partir da raiz do repositório. O Google Analytics é carregado após o visitante aceitar a medição no aviso da página.
